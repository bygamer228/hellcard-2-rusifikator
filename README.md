# HELLCARD 2 (HELLCARD II) — Русификатор Playtest

Неофициальный русификатор HELLCARD II Playtest для Steam: русский перевод интерфейса, карт, предметов, подсказок и реплик.

Unofficial Russian translation for HELLCARD II Playtest (HELLCARD 2).

**Совместимость:** Steam App ID `5054420`, сборка `25208472`, версия игры `0.1.26090911`. Это патч для Playtest; совместимость с другими сборками не проверена.

Перевод охватывает 3 008 строк основного файла локализации: интерфейс, карты, эффекты, предметы, обучение, события и реплики. Перевод подготовлен с помощью ИИ; полная игровая вычитка ещё не пройдена. Текст, встроенный в картинки, озвучка и внешние страницы не входят в этот файл локализации.

## Установка

1. Полностью закройте игру.
2. Скачайте ZIP репозитория через **Code → Download ZIP** и распакуйте его.
3. Откройте папку и запустите **Install-Russian.cmd**. Установщик найдёт Steam и папку игры. Если доступ к папке игры запрещён, запустите этот файл от имени администратора.
4. Запустите игру. Если русский не включился автоматически, выберите его в настройках языка. Дополнительный способ — параметр запуска Steam `-culture=ru`.

Установщик копирует один файл: `Tale/Content/Paks/pakchunk99-Russian_P.pak`. Если там был предыдущий вариант этого патча, он сохраняется в `Tale/Saved/Backups/HellcardRussian/`. Сохранения и оригинальные игровые архивы установщик не меняет.

**Ручная установка:** скопируйте файл `Tale/Content/Paks/pakchunk99-Russian_P.pak` из архива в одноимённую папку внутри установленной игры. Для стандартной библиотеки Steam это `C:\Program Files (x86)\Steam\steamapps\common\HELLCARD II Playtest\Tale\Content\Paks\`.

## Удаление

Закройте игру и запустите **Remove-Russian.cmd** из того же архива. Либо удалите вручную только `Tale/Content/Paks/pakchunk99-Russian_P.pak` из папки игры. Затем перезапустите игру.

## Обновления беты

После обновления игры часть строк может измениться. Установщик сверяет номер сборки Steam и останавливается при несовпадении. Если игра уже обновилась после установки, удалите старый патч до выхода совместимого перевода. Проверка целостности в Steam обычно не удаляет добавленные файлы модов.

## Исправления перевода

Русские тексты находятся в `translations/ru.json`. Ключи, `{подстановки}`, теги `<...>` и идентификаторы значков менять нельзя. При сообщении об ошибке укажите сборку игры и приложите скриншот текста. Это помогает проверить контекст и размер надписи.

## Сборка из исходников

Нужны Windows, Python 3.10+ и установленная поддерживаемая сборка игры:

```powershell
python tools/build.py --game "C:\Program Files (x86)\Steam\steamapps\common\HELLCARD II Playtest"
```

Скрипт скачивает зафиксированные версии [repak 0.2.3](https://github.com/trumank/repak/releases/tag/v0.2.3) и [UnrealLocres 1.1.1](https://github.com/akintos/UnrealLocres/releases/tag/1.1.1) с их страниц выпусков и проверяет SHA-256 перед запуском. Английский файл извлекается из локальной установленной игры в `.build/`.

Сборка проверяет набор ключей, служебные подстановки и теги, затем повторно читает собранные LOCRES и PAK и сравнивает содержимое. Результаты — в `validation.json`; контрольные суммы и версия сборки — в `build-info.json`. Значения имён брендов, технических обозначений и чисел могут совпадать с исходными.

HELLCARD II и игровые материалы принадлежат их правообладателям. Это самостоятельный фанатский перевод, не официальный выпуск Thing Trunk или Skystone Games. Инструменты repak и UnrealLocres принадлежат их авторам и при сборке скачиваются отдельно.
