# HELLCARD 2 (HELLCARD II) — Русификатор Playtest

Неофициальный русификатор HELLCARD II Playtest для Steam: русский перевод интерфейса, карт, предметов, подсказок и реплик.

Unofficial Russian translation for HELLCARD II Playtest (HELLCARD 2).

**Совместимость:** Steam App ID `5054420`, сборка `25208472`, версия игры `0.1.26090911`. Это патч для Playtest; совместимость с другими сборками не проверена.

Версия **0.1.2** содержит 3 852 переведённые записи: 3 008 строк основного каталога и 844 дополнительные записи из игровых объектов. По скриншотам добавлены пропущенные кнопки, награды, статистика, экраны персонажей, меню паузы и выбор карт.

**Если версия 0.1.2 работает некорректно, [скачайте версию 0.1.1](https://github.com/bygamer228/hellcard-2-rusifikator/archive/e0f37021f9b840d9592fe7ff31bef9d6ce44d67b.zip).** Закройте игру, распакуйте архив и запустите `Install-Russian.cmd` из версии 0.1.1.

Перевод подготовлен с помощью ИИ и прошёл языковую вычитку. Составные фразы проверены с учётом русской грамматики. Новые записи проверены при сборке; их отображение на всех экранах ещё предстоит проверить в игре. Текст на картинках, озвучка и внешние страницы в этот патч не входят. Используются родные шрифты игры с поддержкой кириллицы.

Известные остатки: `Location 4` в меню паузы собирается игрой из обычной строки и числа, поэтому языковой файл её не заменяет. Сокращения `m`/`s` в таймере тоже пока остаются. Имена, уже записанные в сохранение обычным текстом, могут остаться на английском.

## Установка

1. Полностью закройте игру.
2. Скачайте ZIP репозитория через **Code → Download ZIP** и распакуйте его.
3. Откройте папку и запустите **Install-Russian.cmd**. Установщик найдёт Steam и папку игры. Если доступ к папке игры запрещён, запустите этот файл от имени администратора.
4. Запустите игру. Если русский не включился автоматически, выберите его в настройках языка. Дополнительный способ — параметр запуска Steam `-culture=ru`.

Установщик копирует один файл: `Tale/Content/Paks/pakchunk99-Russian_P.pak`. Если там был предыдущий вариант этого патча, он сохраняется в `Tale/Saved/Backups/HellcardRussian/`. Сохранения и оригинальные игровые архивы установщик не меняет.

**Ручная установка:** скопируйте файл `Tale/Content/Paks/pakchunk99-Russian_P.pak` из архива в одноимённую папку внутри установленной игры. Для стандартной библиотеки Steam это `C:\Program Files (x86)\Steam\steamapps\common\HELLCARD II Playtest\Tale\Content\Paks\`.

## Удаление

Закройте игру и запустите **Remove-Russian.cmd** из того же архива. Либо удалите вручную только `Tale/Content/Paks/pakchunk99-Russian_P.pak` из папки игры. Затем перезапустите игру.

## Обновления беты

После обновления игры часть строк может измениться. Установщик сверяет номер сборки Steam и останавливается при несовпадении. Если игра уже обновилась после установки, удалите старый патч до выхода совместимого перевода. Проверка целостности в Steam обычно не удаляет добавленные файлы модов.

## Исправления перевода

Основной перевод находится в `translations/ru.json`, дополнительные записи — в `translations/extra.json`. В дополнительных записях редактируйте только `translation`: поля `namespace`, `key` и точный английский `source` нужны для сопоставления с игрой. Ключи, `{подстановки}`, теги `<...>` и идентификаторы значков менять нельзя. При сообщении об ошибке укажите сборку игры и приложите скриншот текста. Это помогает проверить контекст и размер надписи.

## Сборка из исходников

Нужны Windows, Python 3.10+ и установленная поддерживаемая сборка игры:

```powershell
python tools/build.py --game "C:\Program Files (x86)\Steam\steamapps\common\HELLCARD II Playtest"
```

Скрипт скачивает зафиксированные версии [repak 0.2.3](https://github.com/trumank/repak/releases/tag/v0.2.3) и [UnrealLocres 1.1.1](https://github.com/akintos/UnrealLocres/releases/tag/1.1.1) с их страниц выпусков и проверяет SHA-256 перед запуском. Английский файл извлекается из локальной установленной игры в `.build/`.

Сборка сверяет номер Steam-сборки и исходный каталог, проверяет ключи, подстановки, теги и хэши дополнительных записей, затем повторно читает собранные LOCRES и PAK и сравнивает содержимое. Результаты — в `validation.json`; контрольные суммы и версия сборки — в `build-info.json`. Значения имён брендов, технических обозначений и чисел могут совпадать с исходными.

## Состав и авторство

В репозитории находятся русские тексты, скомпилированный языковой патч и скрипты установки/сборки. Для работы нужна установленная игра. HELLCARD II и игровые материалы принадлежат их правообладателям. Это самостоятельный фанатский перевод, не официальный выпуск Thing Trunk или Skystone Games. Инструменты repak и UnrealLocres принадлежат их авторам и при сборке скачиваются отдельно. Реализация CityHash в `tools/locres_tools.py` основана на коде UnrealLocres; уведомление о лицензии MIT сохранено в файле.
